# Client Compass

A static sales workspace for healthcare, beauty salons and skincare businesses in the USA, UK, UAE and wider Middle East. Minimum proposed project value: USD 1,200.

## Features
- Lead records with source evidence and qualification scoring
- Sales pipeline, follow-up dates and proposal templates
- Manual payment tracking and CSV export
- JSON backup and restore in Setup

## Data and limits
This GitHub Pages edition saves lead data only in your current browser profile. Data is not uploaded to GitHub, and there is no account login or cross-device synchronization. Anyone using that browser profile can access the records. Clearing browser storage removes them, so download backups regularly.

Research and outreach are manual. No scraping, autonomous AI agent, email sending, payment processing or guaranteed conversion probability is active. Qualification scores measure recorded evidence, not a probability of closing.

## Hosting
The root index.html contains all application JavaScript and CSS. No install or build is required. Deploy main / (root) through GitHub Pages. No lead records or credentials are included in this repository.
